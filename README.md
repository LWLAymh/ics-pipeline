# Y86-64 Pipeline Lab

面向 CSAPP / ICS 的五级流水线可视化。写入 Y86-64 汇编，在真实模拟信号驱动的数据通路中观察取指、译码、执行、访存和写回。

**在线使用：<https://lwlaymh.github.io/ics-pipeline/>**

## 功能

- 可编辑、编译 Y86-64 汇编；导入 `.ys` / `.yo`，保存当前程序。
- 五级数据通路 SVG，显示各阶段指令、PC、ALU、内存与双端口写回；悬停查看完整信号值。
- **周期动画**：课件式的「指令 × 周期」方格图；当前列滑动高亮，阶段逐周期出现，显示暂停、气泡、分支清空和转发箭头。与单步、回退、连续运行共用同一模拟状态，适用于自定义程序，不含逐周期讲解文本。
- 数据转发优先级、load/use 暂停、预测跳转及失败清空、`ret` 等待。
- 单步、连续运行、速度调节、复位，回退最近 120 个周期。
- 15 个通用寄存器、ZF/SF/OF、流水线寄存器、逐周期时序图、内存和事件记录。
- 19 个教学示例：转发、load/use、分支预测失败、函数调用、数组求和、条件移动、栈指针特殊语义，以及 `03-Arch` 课件中的组合冒险等。
- 动画上方可按主题切换样例；支持专注模式（Esc 退出）、80% / 100% / 120% 缩放和自动跟随开关。滚动时，左侧指令列与顶部周期编号固定可见。
- 无外部运行依赖、字体/CDN 或后端服务；汇编在浏览器中执行，草稿保存在本机浏览器。

## 本地运行

需要 Node.js 22 或更新版本，无需 `npm install`。

```sh
npm run dev
# http://localhost:4173/ics-pipeline/

npm test
npm run build
```

构建产物在 `dist/`，所有静态资源使用相对路径，适配 GitHub Pages 项目站点子目录。

顶部切换「数据通路 / 周期动画」；动画视图也可直接打开 <https://lwlaymh.github.io/ics-pipeline/?view=timeline>。点击动画方格可推进一个周期；滚动、选择文字和查看指令标签不会触发单步。动画从第 1 周期的 F 开始，推进 5 次时钟边沿后显示第 6 周期；顶部计数显示已推进的边沿数。黄色列只显示当前周期，未来阶段不预先填充。动画保留最近 40 周期，长程序可横向滚动；循环中同一地址的不同动态指令使用独立行。默认跟随当前周期，取消后可停留回看；图表获得焦点时方向键用于滚动。专注模式把空间留给动画和控制栏，适合投屏与窄窗口。

## 课件补充示例

示例下拉框的 **08～19** 来自 `ICS26-Slides` 仓库的 `pages/03-Arch.md` 和 `components/pipelineScenarios.ts`。其中有些是课件原指令序列，有些依据课件问题或控制条件构造成完整程序；代码注释标明了来源，并补齐运行所需的入口、栈、数据或 `halt`。

| 编号 | 观察内容 | 运行结果 / 特征 |
| --- | --- | --- |
| 08 | 相邻指令的两路转发 | `%rax = 13`，M、E 两路转发到 D |
| 09 | 隔一条 `nop` 的转发 | `%rax = 13`，W、M 两路转发到 D |
| 10 | 两条 `nop` 与写回转发 | `%rax = 13`，本站 PIPE 通过转发正确执行 |
| 11 | `pushq %rsp` | 压入旧栈指针 `0x200` |
| 12 | `popq %rsp` | `%rsp = %rbx = 0x300`，一次 load/use |
| 13 | 0x200 处的机器码翻译题 | `%rbx = 10`，返回地址为 `0x20b` |
| 14 | 负位移与小端存储 | M[0x100] = `0x1122334455667788` |
| 15 | 预测失败 + `ret`，组合 A | 错误路径被清空，`%rax = 1` |
| 16 | 加载 `%rsp` + `ret`，组合 B | D 暂停优先于气泡，`%rax = 42` |
| 17 | 加载后插入 `nop` | `%rax = 13`，与 07 对比，无 load/use 暂停 |
| 18 | 连续三组 load/use | `%rbx = 12`，三次暂停与折行 |
| 19 | 条件移动与转发 | 不成立的 cmov 不写回；`%rdx = 5`、`%rsi = 9` |

## 模型与输入

以 CSAPP 第三版 Y86-64 PIPE 为模型，五级为 F / D / E / M / W。状态锁存在流水线寄存器中，各级组合逻辑读取同一周期的旧状态，再一起更新。

- 指令：`halt nop rrmovq cmovXX irmovq rmmovq mrmovq addq subq andq xorq jXX call ret pushq popq`。
- 额外支持 Archlab 扩展 `iaddq`。
- 指令集使用第三版的 64 位形式；不接受 `%eax`、`rrmovl` 或 x86 的 `movq`。
- 汇编：标签、十进制 / 十六进制常量、标签 ± 常量、`#` / `;` 注释，以及 `.pos .align .quad .long .byte .zero`。
- `.pos`、`.align`、`.zero` 的布局表达式需要是数值或此前已经定义的标签；指令和数据操作数支持前向标签。
- 入口 PC = 0，15 个寄存器初始为 0；ZF = 1，SF = OF = 0。使用栈的程序必须先设置 `%rsp`。
- BigInt 实现精确的 64 位二进制补码运算与溢出标志；内存为统一的 64 KiB 字节数组，小端序，越界产生 ADR。
- 分支默认预测跳转。失败时清空 D、E；load/use 保持 F、D 并向 E 插入气泡。`ret` 在 W 产生返回 PC。
- 停机 / 异常在 W 停止，抑制年轻指令的寄存器、内存和条件码副作用。
- 图中显示**当前锁存值及当前组合逻辑信号**。STALL / BUBBLE 标记表示下个时钟边沿将执行的动作。
- 时序记录保留最近 500 周期，视图展示最近 40 列。连续运行每 5,000 周期自动暂停；可以继续运行。
- 内存允许写入代码区；与实际流水线一样，已取出的指令不会因后续内存写入而自动重新取指。教学示例不依赖自修改代码。

## 测试

使用 Node.js 内建测试运行器，覆盖示例答案、加载暂停周期数、转发、分支清空、嵌套调用、`popq %rsp` 的写回优先级、溢出、异常与 halt 的副作用抑制、快照回放、目标代码导入及汇编错误。

还将 150 组含随机数据依赖、条件移动、访存与栈操作的程序与独立的顺序 ISA 执行器对比寄存器、内存及条件码。随机种子固定，可重复验证。
